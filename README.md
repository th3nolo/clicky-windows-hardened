# Clicky for Windows — Hardened

A Windows desktop teaching assistant that listens to questions, reads the screen, and responds with voice and visual pointers. Supports cloud AI providers and local models through Ollama or LM Studio.

An independent derivative of [Bitshank-2338/clicky-windows](https://github.com/Bitshank-2338/clicky-windows), based on the original [Clicky](https://github.com/farzaa/clicky) concept. This repository adds dependency verification, permission controls, protected local storage, and model-integrity checks. It is not an official upstream release.

**Status:** experimental development source. No public release yet. Native notebook teaching is under active development; reliable lesson completion and physical microphone, hotkey, and packaged-app acceptance remain unverified.

## What it does

- Ask questions by voice and receive spoken answers, screen pointers, or drawing instructions.
- Choose a cloud provider or an already-installed local model server.
- Add document context, OCR, quizzes, lesson recording, and per-app conversation history.
- Experiment with editable pen strokes in InkNotes, generated by the selected model. See [teaching status and limits](TEACHING_STATUS.md).

## What this derivative changes

- **Dependencies:** a frozen, wheel-only lock with artifact provenance and advisory checks in CI.
- **Permissions:** separate opt-in controls for microphone, screen capture, cloud speech, and external response-provider CLIs.
- **Local data:** Windows DPAPI protection for stored tokens and writing profiles; provider API keys come from the launching process environment.
- **Network and models:** bounded network requests, approved skill hashes, and integrity checks for local models. Clicky does not install or download model runtimes.

Cloud features send the selected request's data to their provider. Clicky is not fully offline. Workspace coding and desktop automation remain disabled in release builds; their source implementations are documented separately.

## Run from source

Requires **Windows 10/11 x64**, **Python 3.12.10**, and **uv 0.11.19**.

Follow [SETUP.md](SETUP.md) to verify dependencies, create the frozen environment, configure a provider, and launch Clicky. Use the committed lockfile; do not install with pip or upgrade packages independently. Clicky does not load `.env` files.

There is no supported public binary to download. Local builds are unsigned test artifacts, not distributable releases. See [BUILD.md](BUILD.md) for packaging and signing requirements.
